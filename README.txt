PIZZA TOWN POS  v1.2
=====================
Pehli baar (ya update ke baad naye PC par):  setup.bat  (Git + Node install, GitHub se link, packages)
Roz chalane ke liye:                        start.bat
Update:  Admin > Settings > Software update > Check for update > Update karein   (internet chahiye)

Admin PIN pehle 1234 hai - Settings mein badal lein.
Mobile: PC aur mobile aik WiFi par, mobile Chrome mein server window mein likha "Mobile par:" address kholen.

Google Sheet: apps-script\Code.gs ko Sheet ke Apps Script mein paste karein (andar likha hai kaise),
phir Admin > Settings mein Web App URL aur Secret key daalen.

Data:  data\ folder (database) aur backups\ - ye GitHub par nahi jate aur update se nahi mitte.
